# Student Grade Tracker

### Description:
A simple Java program that allows teachers to input students' grades and calculates their average, highest, and lowest scores. The program uses **ArrayLists** to store student names and grades.

### Features:
- **Input student names & grades**
- **Calculate average, highest, and lowest scores**
- **Displays all student data neatly**

### How to Run:
1. Clone or download the repository.
2. Open the `StudentGradeTracker.java` file in your Java IDE (like **Eclipse**, **IntelliJ**, or **VS Code**).
3. Compile and run the program.
4. Input the number of students, their names, and grades as prompted by the program.
